# 现有边界与待处理项

[README](../../README.zh-CN.md) · [English](../en/known-issues.md)

以下记录截至 2026-10-28 迁入仓库时的官网状态。本次仓库整理、页脚部署和文档完善没有修复这些问题；后续应逐项实施、验证并记录。

| 范围 | 已观察到的行为 | 影响与后续处理 |
| --- | --- | --- |
| AI 中文简介 | `public/main.json` 的 76 条 `description.zh-CN` 均有字面量问号损坏 | 英文可读；需要对照可靠资料人工补写，更换编码不能恢复已丢失文字 |
| 正式站内部路由 | 2026-10-28 直接请求 `/aitoolbox`、`/mybox`、`/devtoolbox` 为 404，首页为 200 | 客户端导航可用，直接链接/刷新失败；需单独增加并发布 SPA 回退，再分别检查页面及真实静态文件 |
| 开发工具目录 | 五个条目均指向 `https://example.com` | 界面和搜索属于演示，需要换为实际条目后才能作为正式工具目录介绍 |
| 精选项目外链 | 此前线上检查中，配置的 TGWC 与 Lastpush 地址返回 404 | 先向拥有者确认目标；页脚更换账户不会迁移单独配置的项目链接 |
| Live2D 组件 | 浏览器检查中外部脚本出现 `Invalid initWidget argument`、空对象 `hitTest` 错误 | 需要单独对齐 API 或移除；文档采集时排除此组件 |
| 字体分发 | 运行时请求 Google Fonts，中文分片下载曾导致截图等待超时 | CSS 已有系统字体回退；文档采集屏蔽外部字体服务以便重复执行 |
| 目录请求失败 | 请求失败/非数组数据均回退为空数组，无明确错误信息 | 无法区分加载中、搜索无结果和网络失败，需要时增加清晰状态 |
| 标题语义 | `SectionHeading` 把标题渲染成段落 | 后续单独完善标题层级和可访问性 |
| 文档语言属性 | `index.html` 固定 `lang="en"`，界面切换未同步 | 后续让文档语言随 i18n 状态更新 |
| 首页内容时效 | 动态日期为 2026-01-25/26 | 它们是人工内容，不是实时动态流；实际更新内容时再修改日期 |
| 未接入组件 | `CodeBlock`、`Toast` 文件存在，但当前目录页没有使用 | 不能仅凭文件存在就宣称已实现代码示例和复制提示 |
| 搜索能力 | 仅对当前语言做小写子串匹配，无分页 | 跨语言/模糊搜索及大目录性能属于后续工作 |

- `https://github.com/carzygod/Tonspay/TGWC`
