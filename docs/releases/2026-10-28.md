## English

The current official-site source is now maintained as a new independent Git repository targeting `git@github.com:wikigsroom/website.git`, branch `main`. The migration includes the already deployed footer change, explicit Vite deployment configuration, shared assets, 76 AI tools and 18 personal applications. It preserves application behavior while organizing the tooling and documentation around a repeatable maintenance process.

Added English/Chinese README files and paired architecture, schema/content, account/deployment, media and known-issue guides. Ten real page screenshots, desktop/mobile MP4 recordings and two GIFs are indexed in the [media gallery](../media/README.md), with file hashes and source fingerprints in the [manifest](../media/manifest.json). Persistent `AGENTS.md`/contribution rules require future source, bilingual docs, release notes and relevant media to be synchronized and pushed together.

The original `web/` checkout remains separate. Blog source, private research notes, credentials, dependencies, generated builds, old Git history and raw recordings are excluded. This documentation/repository release does not create a new production deployment; the existing application deployment below is the prior footer release.
