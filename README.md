# sidcloud Notes

React + Vite blog built to match the sidcloud Studio visual direction.

## Usage

```bash
npm install
npm run dev
npm run build
```

## Structure

- `src/App.tsx` - app shell, routing, search, filters, archive, article view
- `src/data/posts.ts` - local blog content
- `src/styles.css` - dark glass, neon, responsive styling
- `public/assets/` - local image assets copied from the studio site
